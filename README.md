# 🚀 DAW Task Tracker

Aplicación de gestión de tareas interactiva desarrollada para la asignatura de **Desarrollo de Aplicaciones Web (DAW)**.

## 🛠️ Tecnologías utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Variables CSS y diseño adaptativo.
- **JavaScript (ES6+)**: Manipulación del DOM y persistencia en `localStorage`.
- **Git & GitHub**: Control de versiones y flujo de trabajo estructurado.

## 📌 Funcionalidades actuales
- [x] Crear tareas con niveles de prioridad.
- [x] Marcar tareas como completadas.
- [x] Eliminar tareas de la lista.
- [x] Persistencia de datos en el navegador mediante `localStorage`.

   `git clone git@github.com:tu_usuario/tu-repositorio.git`
